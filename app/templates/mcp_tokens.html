接続方法（Claude などから使う）

このアプリのMCPエンドポイントURLは以下です：

{{ mcp_url }}

Claude Desktop の設定例（claude_desktop_config.json）：
リモートMCP（HTTP）に対応したクライアントで、上記URLと発行トークンを設定します。

{ "mcpServers": { "komonsaki": { "type": "http", "url": "{{ mcp_url }}", "headers": { "Authorization": "Bearer <発行したトークン>" } } } }

対応する主なツール：顧問先の検索・詳細・登録・更新・削除／共有ファイル一覧・削除／受信ファイル一覧／チャット履歴・送信／担当の確認・割当／スタッフ・店舗・受託業務・納税実績の参照 など。
※権限「閲覧のみ」のトークンでは、編集・削除系のツールは表示されません。

⚠️ トークンはパスワードと同じです。第三者に渡さないでください。「削除」権限のトークンは、AIの操作で顧問先やファイルが消える可能性があります。まずは「閲覧のみ」で試し、必要な範囲だけ権限を上げることをおすすめします。
