# eLTAX対応ソフトウェア 公開仕様開示申請 準備ガイド（API方式）

> 本書は、eLTAX公式の申請様式に記入するための**下書き・準備シート**です。
> 提出は必ず eLTAX 公式サイトからダウンロードした最新様式で行ってください。
> 参照: [eLTAX対応ソフトウェアを開発される方へ](https://www.eltax.lta.go.jp/support/software/)

---

## 0. 申請の全体像（API方式）

```
① 公式サイトから様式一式をDL
    └ eLTAX対応ソフトウェア公開仕様開示申込書
    └ （API方式）同意書
    └ 開発概要（審査対象になる場合あり）
        ↓
② 本ガイドの下書きを転記して記入・押印
        ↓
③ 申込書＋同意書(押印/PDF)＋開発概要 を提出
        ↓
④ 事務局の確認/審査
        ↓
⑤ API方式の公開仕様書一式が開示される
        ↓
⑥ 自社アカウント（税理士法人OKSのeLTAX利用者ID）で疎通テスト
```

- **API方式**は「申告データ作成〜電子署名付与〜ポータルセンタ送信まで自ソフトで実装」する方式。
- **同意書への押印**（PDF添付）が必須。
- 「納付情報発行依頼」は**署名省略手続き**で電子証明書は不要（税理士の代理送信でも本人証明書は不要）。

## 2.（API方式）同意書｜確認事項

同意書は概ね次を約する内容です。提出前に社内で確認してください。

- [ ] 開示された公開仕様書を**目的外に使用しない／第三者に開示しない**
- [ ] 仕様に基づき開発したソフトが**eLTAXの安定運用を妨げない**
- [ ] 事務局からの照会・是正依頼に応じる
- [ ] （必要に応じ）**代表者印または社印を押印**しPDF化して添付

> 押印 → スキャン（PDF）→ 申込みフォーム/メールに添付、が一般的な流れです。

## 3. 開発概要（審査対象になり得る）｜下書き

| 項目 | 記入内容（下書き） |
|---|---|
| システム構成 | Flask(Python) + PostgreSQL のマルチテナントSaaS（Heroku）。バックエンドからPlaywright/API方式でeLTAXに接続。 |
| 対象手続き | 地方税共通納税：納付情報発行依頼、納付情報の受取 |
| 電子署名 | 納付情報発行依頼は署名省略手続きのため電子証明書は不要 |
| 認証情報の管理 | 顧問先のeLTAX利用者ID・暗証番号は**Fernetで暗号化保管**（平文非保存） |
| 想定利用件数 | 顧問先 約500社／月次の納付情報発行 |
| セキュリティ | 通信TLS、認証情報の暗号化、権限（管理者以上）による操作制限、操作ログ |

## 5. 補足：申請と並行して進めること

- **RPA骨組み（実装済み）**: `app/utils/etax/eltax_rpa_worker.py`
  - 御社のeLTAX利用者ID・暗証番号が用意でき次第、PCdesk(WEB版)の画面要素を確認して
    `_SELECTORS` を埋め、`SELECTORS_CONFIRMED=True` にすれば即テスト可能。
  - API方式の仕様が開示されたら、同じ戻り値契約のままAPI実装へ差し替えられる設計。
- API方式の公開仕様書は**開示申請の通過後**に入手できるため、本実装はそれ以降。
